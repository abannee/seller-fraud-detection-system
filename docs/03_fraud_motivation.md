# Fraud Motivation & Typologies

## Core Typologies
1. Bust-out fraud — builds trust, then rapidly extracts value before disappearing
2. Stolen goods / inventory fraud — marketplace used as a fencing channel
3. Triangulation fraud — real goods fulfilled via stolen-card purchases from third parties
4. Account takeover (ATO) — fraudster hijacks an established legitimate account
5. Collusion / friendly fraud rings — networked accounts simulate legitimate volume
6. Synthetic identity fraud — fabricated/blended identity with no real traceable person

Each typology has a distinct behavioral signature and will map to specific
investigation questions (Day 6), risk signals (Day 7), and — where possible —
per-typology model validation (Day 12), not just an aggregate fraud/not-fraud label.
